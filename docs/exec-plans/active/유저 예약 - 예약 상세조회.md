### 엔드포인트

`GET /reservations/{reservationId}` — 인증 사용자(Authorization: Bearer {accessToken}) 본인 예약 상세 1건.

**Headers:** `Accept: application/json`, `Authorization: Bearer {accessToken}`

**Path Parameters:**
- `reservationId: string(uuid)`

**Query Parameters:** 없음.

**시스템 처리:**
1. 토큰으로 사용자 식별 (AuthGuard)
2. `reservationId`로 예약 조회. 비존재 시 `404 RESERVATION_NOT_FOUND`.
3. `Reservation.userId === currentUserId` 검증. 미일치 시 `403 FORBIDDEN`. (PARTNER_MANUAL source의 userId=null도 비본인이므로 403)
4. `Reservation.status` + (IN_PROGRESS면 `Artwork.status`)로 `displayState` 계산 — `display-state.util.ts` `calcDisplayState()` 재사용.
5. `totalPrice` = `programSnapshot.price × participantCount` 산출 (D1).
6. `canCancel`, `cancelDeadlineDays` 산출 — D5 계산 규칙(아래 섹션) 적용. `cancelDeadlineDays`는 `Store.cancelDeadlineDays` 원본 직매핑, `canCancel`은 effectiveN 로직으로 BE 내부 계산.
7. `artwork.progressPercent`, `artwork.remainingSteps` 산출 — D6 계산 규칙(아래 섹션) 적용. `status !== IN_PROGRESS` 이거나 Artwork null이면 `artwork` 필드 자체 null 반환.
8. `delivery` 조립 — `deliveryMethod=DELIVERY`이면 `Delivery` 레코드에서 필드 직매핑, `PICKUP`이면 null.
9. `hasReview`, `reviewId` — `Review` 존재 여부 + id 직매핑 (D4).

### canCancel 계산 규칙 (D5 — 2026-06-05 확정)

**기준 시각: KST 날짜 자정(23:59:59 KST).**

1. **status/source 전제 조건**: `status ∈ {PENDING, CONFIRMED}` AND `source === CUSTOMER`인 경우에만 canCancel=true 후보. 그 외 status(CANCELED / IN_PROGRESS / SHIPPED / DELIVERED / PICKUP_READY / PICKUP_DONE 등)는 항상 `canCancel=false`.

2. **effectiveN 산출**: `effectiveN = cancelDeadlineDays ?? 1`. 당일 불가 baseline 보장을 위해 `effectiveN = max(effectiveN, 1)`.
   - `cancelDeadlineDays`가 설정된 경우: 그 값 그대로 사용(단, 0 이하이면 max(값, 1) 적용으로 당일 불가 baseline 보장).
   - `cancelDeadlineDays === null`: N=1 적용(당일 불가 baseline만 적용 → 전날 자정까지 취소 가능).

3. **당일 취소 불가(baseline, 항상 적용)**: KST 기준 오늘 날짜 ≥ `scheduledAt`의 KST 날짜이면 `canCancel=false`. effectiveN에 관계없이 강제 적용.

4. **마감일 판정**: `취소_가능_마지막_날_KST = scheduledAt_KST_날짜 − effectiveN일`. 그 날의 23:59:59 KST까지 취소 가능. 판정식: `오늘_KST_날짜 ≤ (scheduledAt_KST_날짜 − effectiveN)`이면 `canCancel=true`, 아니면 `false`.

5. **응답 필드 분리**: 응답 `cancelDeadlineDays`는 `Store.cancelDeadlineDays` 원본 값 직매핑(null이면 null 노출). effectiveN fallback(=1)은 BE 내부 계산에만 사용하며 응답에 노출하지 않음.

   > **FE minor note**: 불가 dialog "예약 취소는 체험 n일 전까지 가능합니다."의 `n` 치환 — `canCancel=false`일 때만 dialog 노출. `cancelDeadlineDays`가 null이고 당일 취소 불가로 false가 된 케이스에서의 `n` 표기(예: "1일 전"으로 fallback)는 FE가 `cancelDeadlineDays ?? 1` 처리.

**의사코드 (BE):**

```
function calcCanCancel(reservation, store, nowKST):
  if reservation.status not in [PENDING, CONFIRMED]:  return false
  if reservation.source != CUSTOMER:                  return false

  scheduledDateKST = toKSTDate(reservation.scheduledAt)
  todayKST         = toKSTDate(nowKST)

  if todayKST >= scheduledDateKST:                    return false  // 당일 불가 baseline

  effectiveN = max(store.cancelDeadlineDays ?? 1, 1)
  deadlineKST = scheduledDateKST - effectiveN days

  return todayKST <= deadlineKST
```

### progressPercent·remainingSteps 계산 규칙 (D6 — 2026-06-05 확정)

**방식 A: 현재 단계 완료 기반.**

진행 단계 순서(4단계): `DRYING(1) → BISQUE_FIRING(2) → GLAZING(3) → GLAZE_FIRING(4)`.

currentIndex 매핑:

| ArtworkStatus | currentIndex | progressPercent | remainingSteps |
|---|---|---|---|
| DRYING | 1 | `round(1/4 × 100)` = **25** | `4 − 1` = **3** |
| BISQUE_FIRING | 2 | `round(2/4 × 100)` = **50** | `4 − 2` = **2** |
| GLAZING | 3 | `round(3/4 × 100)` = **75** | `4 − 3` = **1** |
| GLAZE_FIRING | 4 | `round(4/4 × 100)` = **100** | `4 − 4` = **0** |

**artwork 객체 반환 조건**:
- `status === IN_PROGRESS` AND `Artwork` 레코드 존재 AND `Artwork.status ∈ {DRYING, BISQUE_FIRING, GLAZING, GLAZE_FIRING}` → `artwork` 객체 반환.
- `status !== IN_PROGRESS`, 또는 Artwork null, 또는 ArtworkStatus가 위 4개 외(`RESERVED`/`VISITED`/`COMPLETED`/`CANCELED`) → `artwork: null`. COMPLETED 등 IN_PROGRESS 외 단계는 본 카드 비노출 대상이므로 계산 대상 아님.

**의사코드 (BE):**

```
const STAGE_INDEX = { DRYING: 1, BISQUE_FIRING: 2, GLAZING: 3, GLAZE_FIRING: 4 }
const TOTAL = 4

function calcArtwork(reservation, artwork):
  if reservation.status != IN_PROGRESS:         return null
  if artwork == null:                           return null

  idx = STAGE_INDEX[artwork.status]
  if idx == undefined:                          return null  // RESERVED/VISITED/COMPLETED/CANCELED

  return {
    id:               artwork.id,
    progressPercent:  Math.round(idx / TOTAL * 100),
    remainingSteps:   TOTAL - idx,
  }
```
