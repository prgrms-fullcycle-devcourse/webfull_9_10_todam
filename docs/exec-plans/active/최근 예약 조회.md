## API Contract (스냅샷)

<!-- 신규 contract 만들지 않는다. 기존 plan의 contract를 SSOT로 참조 + 재사용 필드만 고정. -->

### 재사용 엔드포인트 (기존, 변경 없음)

`GET /reservations/me?limit=1` — 인증 사용자(Authorization: Bearer {accessToken}) 본인 예약 **최신순 1건**.

- 정렬: 최신순(기존 contract 고정). `limit=1` → `data.reservations[0]` = **가장 최근 예약**.
- `cursor` / `status` 쿼리는 본 위젯에서 **미사용**(전체 최신 1건만 필요).
- `nextCursor` / `hasMore`는 위젯에서 무시.
- 빈 결과: `data.reservations = []` → 빈 상태 렌더.
- 401 → 비회원/미인증 → 빈 상태(비회원) 렌더(상세 분기는 §UI 규칙).
- 500 → 네트워크/서버 오류 상태(위젯 자리 비표시 또는 오류 placeholder).

> 응답 봉투·항목 전체 스키마·displayState 구조·에러 본문은 SSOT(`user-예약-나의 예약조회.md` §API Contract)를 따른다. 본 plan에서 재정의하지 않는다.

### 재사용하는 항목 필드 (`reservations[0]`)

위젯이 바인딩하는 필드만 — 전부 기존 contract에 존재:

| 필드 | 타입 | 위젯 용도 |
|---|---|---|
| `id` | string(uuid) | 예약 상세 이동 경로 (`/my/reservations/{id}`) |
| `storeName` | string | 공방명 |
| `programTitle` | string | 클래스명 |
| ~~`category`~~ | ~~string~~ | **제거됨 (2026-06-05 회의 결정)** — "도자기" 1종뿐, SSOT plan에서 삭제. meta line은 `{storeName}・{hh:mm}` 사용. |
| `scheduledAt` | string(ISO8601) | 예약 일정 |
| `participantCount` | number | 인원 |
| `status` | ReservationStatus(8값) | 상태 배지 + CTA 분기 입력 |
| `displayState` | `{ label, description, subLabel\|null }` | 상태 라벨/메시지(서버 계산, 그대로 렌더) |
| `createdAt` | string(ISO8601) | (최신순 정렬 근거, 표시 선택) |

`ReservationStatus`(정본 8값): `PENDING` `CONFIRMED` `CANCELED` `IN_PROGRESS` `SHIPPED` `DELIVERED` `PICKUP_READY` `PICKUP_DONE`.

### 상태별 메시지 (기존 SSOT 재사용)

`displayState.label` / `displayState.description` / `displayState.subLabel`을 **서버 계산값 그대로** 렌더. 문구 테이블은 SSOT(`user-예약-나의 예약조회.md` §"displayState 정본 매핑")를 따른다. FE는 계산하지 않는다.

### 상태별 CTA — **없음 (2026-06-09 확정)**

**결정:** 최근 예약 카드에 상태별 별도 CTA 버튼은 없다. 기능명세의 "예약 상태에 따라 CTA를 노출한다"는 상태별 `displayState`(label/description/subLabel) 노출 + **전체 카드 클릭 시 예약 상세 이동**으로 해석한다. Figma 메인 "최근 예약" 카드 Description #5와 일치.

- **카드 전체** = `<Link href="/my/reservations/{id}">` — 어느 상태에서나 동일.
- 상태별 버튼 컴포넌트: **불필요**. 렌더하지 않는다.
- 상태별 메시지는 `displayState.label` / `displayState.description` / `displayState.subLabel`(nullable) 그대로 표시.

- In (FE-only):
  - 메인 화면 "최근 예약 위젯": 최신 예약 1건(`GET /reservations/me?limit=1`) 표시 — 공방명/클래스명/일정/인원/상태 배지/displayState 메시지(label·description·subLabel).

  - 네트워크/500 오류 시 위젯 처리.
- Out:
  - BE/엔드포인트 변경, 신규 contract (기존 `GET /reservations/me` 재사용).
  - 예약 **목록 화면**(`/my/reservations`) — 별도 plan `user-예약-나의 예약조회.md`.

  - 상태 배지 컴포넌트 신규 제작 (기존 `ReservationStatusBadge` 재사용).
